# Roman Gutmann – Portfolio

Zweisprachiges Bewerbungsportfolio auf Basis von Astro, TypeScript und Tailwind CSS.

## Entwicklung

```sh
pnpm install
pnpm dev
```

## Prüfung und Build

```sh
pnpm check
pnpm build
```

Die statische Ausgabe wird unter `dist/` erzeugt und per GitHub Actions auf GitHub Pages veröffentlicht.

Der unveränderte Stand der ersten statischen Homepage ist über den Git-Tag `legacy-static-v1` gesichert.
